trends-monitor

Automated AI trend tracking · GPT-4 + GitHub Actions

Google Trends data, 4× daily. AI-generated tweets and blog drafts. Delivered to your inbox for under $0.04/month. No server.

> how it works

GitHub Actions (cron 4×/day)
  ↓
google_trends.py  ──► pytrends API (PL + US)
  ↓
deduplicator.py  ──► 24h seen_trends.json
  ↓
generator.py     ──► gpt-4.1-nano tweets
article_gen.py   ──► gpt-4.1-mini blog drafts  (morning only)
  ↓
mailer.py        ──► HTML email digest
publisher.py     ──► auto-commit drafts/ to repo
↻ Google Trends refreshed 4× daily — Poland & USA
✦ GPT-4.1-nano tweets per trend · GPT-4.1-mini daily article drafts
◎ Smart 24h deduplication — each trend appears once per day
⌗ Zero-config markets — add a country in one line of config.py
$ Under $0.04/month in API costs
